# Mariebelle G. Bajan — Personal Portfolio

A personal portfolio website for **Mariebelle G. Bajan**, a second-year
Bachelor of Science in Information Technology student at
**Kabankalan Catholic College**.

## Project Overview

This portfolio presents Mariebelle's academic journey, the skills she is
currently learning, and the academic/practice projects she has built while
studying web development. It features an elegant, editorial-inspired design
with a warm ivory, blush pink, and muted rose palette.

## Website Features

- Responsive navigation with mobile-friendly menu
- Split-layout hero section with profile card
- About section with personal information cards and interests
- Skills grid with honest skill-level labels (Beginner / Developing / Familiar)
- Selected Works section with three varied project card layouts
- Education timeline
- Personal goals section
- Contact section with information placeholders and a front-end form demo
- Footer with quick links, social placeholders, and back-to-top link
- Smooth scrolling, accessible focus states, and `prefers-reduced-motion` support

## Technologies Used

- HTML5
- CSS3 (custom properties, Flexbox, Grid, media queries)
- Vanilla JavaScript (mobile nav toggle and form demo only)
- Git & GitHub
- GitHub Pages (deployment target)

## Local Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/bajan-project-1.git
   ```

2. Open `index.html` in a web browser, or serve the folder with any
   static file server (e.g., `python -m http.server` or XAMPP/Apache).

## GitHub Pages Deployment

1. Create a new repository named `bajan-project-1` on GitHub.
2. Upload all source files (or push via Git):

   ```bash
   git remote add origin https://github.com/<your-username>/bajan-project-1.git
   git push -u origin main
   ```

3. Open the repository on GitHub and go to **Settings**.
4. Navigate to **Pages** (left sidebar, under "Code and automation").
5. Under "Build and deployment", select **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`.
7. Click **Save**.
8. Wait a minute, then visit `https://<your-username>.github.io/bajan-project-1/`.

> Note: The site uses relative paths, so it works at any base URL.
